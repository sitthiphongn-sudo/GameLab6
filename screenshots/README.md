# ภาพหน้าจอประกอบการส่งงาน

วางภาพตามชื่อไฟล์นี้ (PNG) แล้ว Commit ขึ้น GitHub — ภาพจะแสดงใน README หลักอัตโนมัติ

| ไฟล์ | ถ่ายตอนไหน |
|---|---|
| `01_blender.png` | Blender หลังรัน `make_character.py` — Viewport โหมด Material Preview (กด Z → Material Preview) เห็นตัวละครเต็มตัว + แท็บ Scripting หรือ Outliner |
| `02_mixamo.png` | mixamo.com หลัง Auto-Rig เสร็จ — ตัวละครกำลังเล่นท่า (เช่น Idle) ในหน้า Animations |
| `03_godot_editor.png` | Godot: หน้าต่าง Advanced Import Settings ของ `hero.fbx` ที่เลือก Skeleton3D และเห็น Bone Map สีเขียว |
| `04_gameplay.png` | กด F5 กำลังเล่นเกม (ตัวละครกำลังวิ่ง/ฟันไห เห็น HUD Coins/Time) |
